disky

Scans this Mac's disk on a schedule. Your scans stay on this Mac unless you configure an upload destination.

Full Disk Access

…

Without it, scans skip macOS-protected folders (Mail, Messages, Safari, app containers, the Trash) and count them as unreadable. In System Settings → Privacy & Security → Full Disk Access, turn on disky (or add it with +). This page updates by itself.

What to scan

Your files, apps, Homebrew, system folders. Some system folders require root and are reported as unreadable; Full Disk Access does not grant root.

Schedule

A scan missed while the Mac sleeps runs when it wakes.

Site

Upload to the site

Choose disk.rbw.sh (or dev) under Site to connect this Mac to it.
Connect this Mac to : each scan uploads its listing there and the site builds the index, so nothing is indexed or kept on this Mac. Sign in to the site as an admin in the disky window first.

Alerts

A failed or missed scan alerts you. Add Pushover to get those on your phone too: your user key and an application token from pushover.net. They're kept in your Keychain.

File previews

Not set up. The hosted site can preview files on this Mac through a Cloudflare Tunnel: disky tunnel set TEAM AUD CLIENT_ID, then disky tunnel token (reads the connector token from stdin into the Keychain).
Admins open files through an outbound-only tunnel; each request must be signed by your Cloudflare Access app. Applies right away. Off, previews say the laptop is offline.

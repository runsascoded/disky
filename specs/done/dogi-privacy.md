# Deployment-level preview privacy

Status: 2026-10-12. Shared implementation and regression coverage in `cloud`; CW/GCS/R2 deployment rollout is owned by their respective worktrees. No deployment or migration is performed by this checkpoint.

`OG_ANONYMOUS=generic` is the default for private deployments (unset or unrecognized values fail closed). A plain root/deep link, or an invalid, expired or revoked explicit share, gets a generic branded card: no tree geometry, path/owner names, totals, counts, scan dates or data-derived empty/error details. The card endpoint returns before scan, ledger, registry, subtree or staging reads and before warming. Credential verification may read only the relevant credential rows. The middleware intercepts anonymous card-bearing HTML routes before their page Functions, so `/staged` cannot leak counts through its description or even query protected staging data.

`OG_ANONYMOUS=shape` explicitly retains the previously approved anonymous view geometry and totals. GCS must configure this in preview and production before deploying this shared change if it intends to preserve that policy. Public `AUTH_MODE=public` deployments default to shape; an explicitly unknown policy still fails closed. CW and OA R2 should retain the generic policy. This is independent of `OG_CARDS`: that flag controls detailed/shape HTML metadata stamping, not direct image access. Generic private HTML metadata remains safe even when the flag is unset; static `/og.jpg` branding/content still belongs to each deployment.

Existing live, explicitly shared `og=` tokens and `key=` grants retain detailed previews. The image signature covers the view, credential, expiry and render metadata. Credential liveness is checked before every detailed cache lookup. Revocation/expiry downgrades to the configured anonymous policy; browser sessions alone never create detailed public previews. Full images and stamped HTML are `private, no-store`.

Image URLs and internal cache keys include the current policy and render version (`policy`, `r`). Restricted anonymous cards use one generic, view-independent cache entry and never query a previous shape/full entry. Previously unversioned generic URLs return `no-store`; newly stamped generic URLs can be publicly cached because they contain no protected data. The server cannot retract images already copied or externally cached under old URLs; rollout should re-fetch unfurls and, where applicable, purge known legacy URLs.

Map/user/owner-view metadata resolves a concrete scan into the signed image's `s` parameter. This render-only parameter is excluded from the canonical credential view, so existing per-view tokens remain valid, while images actually draw the pinned scan and new scans produce different image URLs. Unversioned shape requests revalidate externally and resolve the current scan before edge lookup; scan-versioned keys prevent stale latest results. Staged cards keep their existing plan/scan version. Comparison metadata explicitly says the card previews the after snapshot, not a computed diff.

Tests reproduce the prior public totals and stale latest URL behavior, then pin generic text, zero protected reads/warming, HTML route interception, signature expiry, revoked-cache downgrade, valid detailed shares, explicit shape behavior and policy cache separation. Local workerd/CIC checks exercise the real HTML/card endpoints without remote data bindings; deployments must additionally verify their real explicit-share flow and warmed caches before production rollout.
